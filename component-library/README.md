## Search by keyword

```bash
grep -i 'glass' components.json
jq '.components[] | select(.tags[] | contains("glass"))' components.json
```

## Add new components

Edit `components.json` and follow the schema:

```json
{
  "name": "Component Name",
  "source_url": "https://...",
  "category": "button|menu|animation|shader|3d|effect|card|input|layout|nav|loader|background|component",
  "tags": ["tag1", "tag2"],
  "description": "What it does"
}
```
